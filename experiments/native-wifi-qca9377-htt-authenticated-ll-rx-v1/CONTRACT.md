# Authenticated low-latency RX bridge — new working scope

Immutable source is ath10k6b5a2b7d9bc156e505f09e698d85d6a1547c1206. `ath10k_htt_rx_h_mpdu` derives decrypted status from actual cipher, last-MSDU FCS/decrypt-error/peer-index flags, not a caller boolean. For the INORD path `fill_crypt_header=false`: an authenticated data MPDU sets DECRYPTED/IV_STRIPPED/MMIC_STRIPPED. RAW undecap trims FCS4, CCMP MIC8, removes the IV8 and clears Protected in the returned802.11 header. The Native-WiFi path reconstructs the original header from retained hdr_status and has different firmware-stripped layout. Offload headers lack the hardware descriptor and cannot use this proof.

The first bounded bridge will support actual owned RAW single-MSDU, nonfragment/nonoffload CCMP only, plus strict current peer/vdev/key epoch/GTK initial-RSC and staged48-bit PN. It must re-decode the exact INORD, map identity, completion and real CommonBuffer ownership; use a DMA acquire fence; validate current ACTIVE47/actual official boot asset and exact current local station key eligibility. Cipher eligibility, PN metadata or AP-authorized status alone cannot deliver plaintext.

The official firmware/container and current chip boot context are a trust boundary pinned by actual compiled policy/asset/boot-owner objects. No boolean `firmware_trusted`, `authenticated` or `PN_VALIDATED` is accepted. Hardware authenticated classification derives from the real retained descriptor and source error fields. The candidate APIs stage a copy of the frozen PN ledger. Only qauth_native_commit commits it after source-derived authentication in the actual official live firmware context, exact raw length/header/IV/keyid/PN/peer joins, decapsulation and bounded retained output construction. No callback/poll/refill/release may occur between output publication and PN assignment. Rejected, unsupported, malformed, stale, replayed or output-alias inputs leave the original ledger unchanged.

RAW input must contain actual header, IV, decrypted body, MIC and FCS bytes with source-defined bounds. Missing/stripped crypto bytes do not justify invented software decryption. TKIP/WEP/GCMP, management/monitor frames, fragments, A-MSDU chains, unsupported Native-WiFi/Ethernet/SNAP decap and offload remain explicit gaps in the first profile. The current frozen plain data path keeps protected quarantine until a new derived adapter directly installs this verified backend; it is never relaxed by a caller flag.

No hardware operations, keys/credentials, BLE, signing, native64 edits or frozen plain edits occur here. Native C/ASAN/COFF validation runs only on Yukabox. Synthetic positive fixtures are not physical firmware/RX evidence.
