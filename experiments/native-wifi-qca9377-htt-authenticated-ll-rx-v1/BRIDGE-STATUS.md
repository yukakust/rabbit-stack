# Offline authenticated RAW RX bridge

`auth_raw.c` derives the pinned ath10k RAW INORD decryption/error classification, removes actual CCMP IV8/MIC8/FCS4, constructs bounded 802.11/Ethernet candidates and stages the frozen PN ledger on a copy. Rejection leaves the caller ledger/output unchanged. Its first proof is422,348 ASAN/UBSAN checks and five actual COFF objects on Yukabox. `evidence/core-stage` preserves this earlier proof and excludes the later native wrapper.

`auth_native.c` resolves the sole current pending buffer from the actual47 owner array/CommonBuffer, acquire-fences and copies actual bytes, checks ownership freshly observed at the same cooperative tick and the pinned official boot asset, then binds current local STA eligibility to separately retained PTK/GTK operations with actual DMA and fresh owned SEC indications. It receives no packet pointer or authenticated/installed Boolean from the caller. Exact key producer pins: header3bc55b66 / C a06073fc, station glue report7094d754. Complete separate actual-producer ASAN/UBSAN case30 plus three COFF objects pass; `evidence/native-stage` preserves the exact compiled fixture, changed dispatcher, log/report/objects.

`qauth_native_candidate` leaves the original PN ledger unchanged. `qauth_native_commit` requires a canonical-zero retained output slot; fully checked output publication and PN assignment follow consecutively without callback/poll/refill/release. Replayed buffer/address/PN or reused output reject without advancing the ledger. DMA/pending ownership remains intact for a separately checked consumer/refill. No API refills/frees DMA, clears the frozen plain quarantine, opens a controlled port or delivers data to a network stack.

The native fixture executes actual compiled boot/47map/RX/key producer code with modeled MMIO. External core state/protection callbacks are deliberately synthetic; no mature handshake or production authority is created. Controls include closed local state, stale tick, wrong key epoch/receipt, incomplete received-chunk mask, wrong official digest, missing capacity, map/output alias, decryption error, exact output/PN commit and replay rejection. Source firmware_chunks.received is a chunk BITMASK (12chunks→4095), not bytes. No physical authenticated RX/key/IP result is claimed.

RAW single-MSDU, nonfragment/nonoffload CCMP is the only supported decap profile. Native-WiFi/Ethernet/SNAP, chained MSDU and firmware-stripped missing IV/MIC layouts remain unsupported. Source references are pinned ath10k h_mpdu/h_undecap_raw and QCA9377 descriptor-v1, never invented software decryption.

The two new adapter COFF objects total text3614/rdata32/bss0 bytes. They require reviewed memcpy/memset/compiler-rt __chkstk and actual runtime/station/PN functions. Whole EFI/provider ABI integration and final image/pool/stack cap proofs are not performed. Protected TX, actual mature callback→local eligibility, other decap profiles and real target-stop remain separate work. The frozen plain driver and native64 remain unchanged; no hardware admission, BLE, signing, credentials or session mutation occurs here.
