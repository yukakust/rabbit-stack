## Smallest concrete integration

1. First obtain actual60 full MAIN/BMI_DONE/HTC/INIT TX + parsed WMI READY and exact
   stop/all14-owner evidence.60 currently requests prefix stop when startup returns
   success: `fullboot_build.py:sources`. It does NOT scan. A released60 acquisition
   cannot be reused:61 must repeat boot under its own identity and adopt persistent
   lifetime immediately after genuine READY, BEFORE the diagnostic success stop.
2. Port the existing corrected55 production scan join onto reviewed60 bootstrap,
   preserving current world19. Entry points: persistent-native `qca_persistent_*`,
   persistent-RX `qca_rx_*`, persistent-TX `qca_tx_*`, scan-native-profile-v1
   `qca_native_scan_begin/poll` with the explicit v2 transformations in
   scan-native-profile-v2/scan_build.py. Do not execute old55 source generation over
   new60: it inherits old52/53 generators and would overwrite identity/telemetry.
3. Revalidate signed GE/actual board108/channel-policy provenance and target binding,
   observed SERVICE_READY bands and actual READY MAC. Hardware capability endpoints
   never authorize channels. Existing scan_policy + verify_policy_binding support
   13 passive2.4GHz legacy20MHz channels; no active probes, country override or key.
4. The existing coordinator sends ordered SCAN_CHAN_LIST → PDEV_SET_REGDOMAIN →
   VDEV_CREATE0 using actual READY MAC → passive START_SCAN. Actual CE3 DMA completion
   only orders commands; it is not invented firmware ACK/created/connected evidence.
   RX pump alone applies HTC incremental credits; coordinator uses owned dispatch,
   never station_scan_receive/scan_stop_receive after the pump (double credit risk).
5. Keep v2 real54 corrections: minimum24-byte scan-event prefix with retained suffix,
   nonterminal reason6 allowed,16 bounded unknown archives/two-head draining and
   accepted wrongSSID/duplicate management-frame archival. Do not regress to v1
   archive2 blocking STARTED/FOREIGN or exact24/reason0 false rejection. Archive16
   saturation, credit starvation, command/scan/STOP/overall deadline all remain bounded.
6. QCA MGMT_RX0x7001 → qca_wmi_beacon_rx → existing beacon parser. Only claim target
   after actual matching STARTED, same native/radio epoch, completion > start_floor,
   metadata frequency inside reviewed policy/live channel and accepted nonhidden
   exact16-byte SSID `SILK_56E35E_Plus`, BSSID and owned raw frame. No guessed HTT
   layout. An unsupported actual envelope remains owned/exported; STARTED alone is
   not network discovery. The v2 match-change is needed to retain the first target
   rather than let a wrongSSID occupy the sole observation.
7. Terminal or bounded STOP → quiesce → real adapter stop/BME-off/IRQ proof → all14
   mappings/pin/PCI owner release. Timeout or terminal alone never clears owners.
   Preserve status + all22 owned-export slots; capture all110 pages twice after
   quiesce, prove stable bytes, then parse retained observation. At terminal live
   frequency0 is expected; decoder must use retained RX/policy/epoch, not invent a
   current channel. scan-observer-v3 contains the corrected terminal decoder logic.

## Integration gates that remain

-60 telemetry and55 export handles collide: prefix service29..51 vs QSCN32..34 and
 raw service35..255.61 needs an explicit tested ATT layout, or use QSCN/export only
 instead of prefix GATT. Do not silently stack both services or change frozen files.
- Existing observer-v3 pins generation55/candidate/source/receipt. A new collector
 must bind actual61 candidate and Root's actual APPLIED session; do not repurpose55.
- Need a new source-closed full EFI profile, native model regression (real54 archive
 blockers + scan prefix28/reason6 + actual matched target + unsupportedMGMT + STOP/
 faults/credit/badpolicy/owner and GATT range cases), ASAN/COFF on Yukabox, repeated
 wholeEFI + world19 normal/EMPTY QEMU, exact immutable generated bytes and new public
 admission. None is proved by this read-only audit.
- Physical61 scan after verified60 remains required. Discovery may fail even with
 genuine STARTED if firmware returns no supported WMI management frame; retain
 actual bytes first. Neither61 nor this audit performs association, WPA, DHCP/IP,
 Yukabox exchange or Unreal. Scan needs no Wi-Fi password.
