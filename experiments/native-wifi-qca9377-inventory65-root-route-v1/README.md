Uses frozen64 actual full firmware/boot/ECHO/HTT/passive scan classification,
all14 released and an independent exact classifier replay. Before signing65,
read a fresh RFS64 and exact544 release value under the common state lock.
Archive native64/firmware64/public evidence/observation durably before retiring
the completed trial. Reserve one signing intent; sign the exact reviewed65
package once. Resume only its saved packet/session, never fabricate an applied
receipt or clear a live trial. No firmware upload/RF/GetRNG/MSR/credentials.

Root gate binds every freeze/source/evidence/compiler input and actual PE size,
world19 plus the tested Mac sequential512/448 reader. Native/ASAN/COFF/QEMU run
on Yukabox; Mac signer and BLE host reader run locally. Decoded public inventory
is physical observation, never device attestation or strong entropy approval.
The future protected provisioning still requires approved native entropy,
internal Dell key generation, full physical QR pinning and local password entry.

continue65.py is the only bounded controller. No competing BLE operations.
Failures retain exact logs/session; after a signing/retirement failure do not
blindly recreate an intent. Read current state/evidence before recovery.
The one-hour retry budget is checked between bounded operations. A current
operation may finish beyond it; the outer watchdog exceeds all common sender
operation budgets. In an interrupted operation inherited lock owners must exit
before any recovery attempt. A crash after signing may leave native_pending
without Root metadata; inspect preserved artifacts instead of signing again.
