# Native station glue — work in progress, no admission

The new glue calls actual `qdp_submit_mgmt`, `qdp_poll_dma`, `qdp_receive` and `qdp_quarantine` functions; there are no production substitutes or mock confirmation callbacks. It begins only after actual source-bound START/PEER_CREATE/PEER_MAP and live47 data-path adoption/ring/aggregation publication. It serializes the existing source-proven auth/association wire, pins actual published CE cookie/nonreused HTT MSDU id/floor, and joins separate actual CE DMA and fresh owned HTT completion plus addressed AP management response. NO_ACK/DISCARD/POSTPONE faults remain errors; DMA alone is not air acknowledgment. Ambiguous publication faults retain owners and quiesce through the actual backend.

The sole runtime dispatch must route real owned PEER_MAP/UNMAP/SEC_IND to the station decoder before data-path INORD decode; their type numbers are not RX indications. All event credits remain the persistent RX producer's responsibility. Duplicate mapping does not create a peer or reset state. Fresh deauthentication/unmap revokes. Caller must serialize dispatch/publication/stop and never replay already taken events. No pointer may survive DMA refill.

`qsg_eapol_frame` implements only the pinned mac80211 station 3-address ToDS RFC1042/EtherType888e construction for an actual associated/mapped pre-key station. It rejects post-key traffic because real protected TX is not implemented. It returns copied bytes only; transport acceptance is not AP receipt or controlled-port authority. Root private children role2 integration is needed for the full mature runtime under the unchanged image cap. The direct function join is compiled into the actual full-producer ASAN entrypoint with a source-pinned final data-path/transitive closure. Dispatcher instrumentation is explicitly model-only; there is no complete integrated EFI/native candidate or physical admission.

The actual CE/RX model join passed positive, NO_ACK, wrong-peer, missing-DMA and missing-SEC cases. Remaining work requires mature callback ABI binding, asynchronously published WMI key to synchronous mature set_key via a bounded cooperative owned-RX pump, source-exact installed peer/key epoch and SEC_IND match, authenticated LL RX stage/commit PN, actual protected TX, and genuine all47 owner stop. Successful arbitrary callback/firmware PN_VALIDATED input is not a substitute. Protected RX remains quarantined; no controlled port/IP/TLS authority exists here.

The new asynchronous `key_operation.c` calls the actual sole persistent CE3 WMI publisher. It records a pending key only on actual POSTED/DMA_DONE after publication, with the pre-publication owned RX floor and real cookie; first-install host RSC is kept outside the primary WMI command because that generator has no sequence argument. A success requires both matching actual CE3 DMA closure and real fresh sole-pending peer/cipher/cast SEC_IND; it does not prove frame MIC or target key-byte equality. After both close, it retires the same request and wipes CPU command plus the actual idle CE3/page7 4096-byte buffer. A fault retains owners and revokes radio work; no false all47 release. Actual Yukabox ASAN/UBSAN/COFF models now exercise these functions through the actual producer CE/RX/47-map fixture. In role2 architecture the mature synchronous set_key waits on this bounded operation while the parent cooperatively services its real mainloop; no new HCI timer or resident spin fix is introduced. Final source/model proof must establish the serialized parent-owned request and secret lifetime before any integration/admission.

Accepted auth/assoc raw records are copied into two retained slots before the owned RX head is consumed. Empty valid HTC/trailer records are preserved in a bounded eight-record diagnostic archive; the sole RX producer already applied their credits. Overflow revokes and retains the current owned record. Key operations retain raw SEC and rejected SEC plus immutable publication cookie/DMA completion serial, so PTK and GTK receipts must be separate objects until epoch teardown. The same actual LIVE_DONE scan CE3 publisher is borrowed, preserving serial continuity; creating a second CE3 context is refused.
