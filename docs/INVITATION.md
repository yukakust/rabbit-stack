# An invitation to Rabbit Stack

Rabbit Stack is an open research journey toward a computer that can turn human intent
into effects across many kinds of hardware without asking us to trust opaque generated
code. A language model may propose a world, but deterministic machinery must validate
its authority, compile it for a specific target, measure the result, and preserve a way
back.

The project begins with only 32 explainable RV32I bytes and grows carefully toward a
portable World IR, replaceable Target Packs, recoverable physical deployments, and an
LLM interface for creating new worlds. Every milestone must be reproducible, falsifiable,
and honest about the layers still present.

If you care about compilers, operating systems, verification, hardware, AI safety, or
new ways for humans to shape computers, you are invited to inspect the evidence,
challenge the assumptions, reproduce the experiments, and help us discover what should
exist next.

**One intent. Many bodies. One verifiable meaning.**
